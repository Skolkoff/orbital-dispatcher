# Орбитальный диспетчер

«Орбитальный диспетчер» — учебный тренажёр по координатной плоскости для учеников 5–6 классов. Шесть модулей и 30 заданий ведут от устройства сетки и упорядоченных пар к отрицательным координатам, маршрутам и построению фигур. Перед практикой ученик читает короткий урок с правилом, примером и вопросом для самопроверки.

На главной есть отдельная свободная миссия: ученик задаёт маршрут космического корабля соседними координатами, обходит случайно расставленные астероиды и проверяет план в полёте. При столкновении можно исправить путь, а после безопасной посадки видны время и очки. Эта игра помогает применить координаты и планирование маршрута, но не меняет результаты прохождения учебных модулей.

Задания чередуют выбор ответа, построение точки, ввод координат, число, маршрут и фигуру. После ошибки тренажёр объясняет следующий шаг и предлагает подсказки. Проходить курс можно без регистрации: прогресс хранится в браузере. По желанию ученик создаёт аккаунт и переносит туда анонимный прогресс; после входа прогресс аккаунта сохраняется в MySQL и синхронизируется между устройствами. Frontend — React, TypeScript и Vite; аккаунты и прогресс обслуживает Laravel API с сессиями Sanctum.

## Quick start

Для полного приложения нужны Node.js 22.13+, PHP 8.3+, Composer 2 и MySQL 8.4. В [инструкции по разработке](Docs/DEVELOPMENT.md) описаны настройка базы, Laravel, запуск обоих серверов и тесты.

После установки зависимостей и настройки `server/.env` запусти в первом терминале:

```sh
cd server
php artisan serve --host=127.0.0.1 --port=8000
```

Во втором терминале из корня проекта:

```sh
npm run dev -- --host 127.0.0.1
```

Открой [http://127.0.0.1:5173](http://127.0.0.1:5173). Гостевой режим и свободная игра доступны без аккаунта; для регистрации и синхронизации нужен Laravel API.

## Checks

```sh
npm run lint
npm run typecheck
npm run test
npm run test:e2e
npm run security:check
npm run build
npm run test:preview
```

Для Playwright один раз установи браузер командой `npx playwright install chromium`. Серверные проверки запускай из `server/`:

```sh
composer audit
vendor/bin/pint --test
php artisan test
```

Проверки браузера и Laravel используют MySQL; тестовая база `orbital_dispatcher_test` отдельно описана в [инструкции по разработке](Docs/DEVELOPMENT.md). Сканеры Gitleaks и Semgrep нужны локально для `npm run security:check`. GitHub Actions запускает проверки для изменений в ветке `product`.

См. [обзор продукта](Docs/OVERVIEW.md), [учебный план](Docs/LEARNING-PLAN.md), [разработку](Docs/DEVELOPMENT.md) и [безопасность](Docs/SECURITY.md). Для демонстрации используй вымышленные данные и тестовые email-адреса.
