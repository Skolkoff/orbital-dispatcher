# Product overview

«Орбитальный диспетчер» is a Russian-language coordinate-plane trainer for grades 5–6. Space-themed missions will help pupils read ordered pairs, find points, and reason about movement on a coordinate grid.

The planned five missions cover a point in the first quadrant, an ordered route, negative coordinates, axis reflection, and coordinate displacement. Pupils will receive hints, explanations for wrong answers, retries, and progression after correct answers. The intended experience supports touch, keyboard interaction, and mobile through desktop layouts.

The current implementation is the npm project foundation with a minimal Russian introduction. Mission screens, answer checking, and progress are not implemented yet.

The frontend phase uses mock services. Future local demo progress will store completed mission IDs only. No authentication, real passwords, personal data collection, backend connection, or production deployment belongs to this stage.
