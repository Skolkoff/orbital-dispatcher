# Product overview

«Орбитальный диспетчер» is a Russian-language coordinate-plane trainer for grades 5–6. Six connected modules contain 30 progressively harder exercises, starting with the grid and ordered pairs and moving through negative coordinates, tables, routes, and coordinate geometry.

Each module opens with a short lesson: one rule, one worked example, a diagram, and a recall prompt. Practice rotates among six response modes: choice, point plotting, coordinate entry, number entry, ordered route, and shape construction. Wrong answers get a focused correction and progressive hints. A correct answer completes the task; a separate confidence measure reflects independent first answers and later review.

The dashboard introduces the goal and reports solved tasks, first answers, attempts, and hints. The course map shows locked, available, and completed modules; the skills screen tracks evidence for each topic. Interactive grids support touch, pointer, keyboard, and coordinate fields. Hash navigation, responsive layouts, and local progress persistence support static hosting and resume in the same browser.

The home screen also opens a separate free-play route mission. Each map uses integer coordinates from −4 to 4, a generated start and goal, and asteroid obstacles. Learners enter one neighboring point at a time, test the route with an animated spacecraft, and correct it after a collision. A safe landing shows elapsed flight time and a score based on extra steps compared with the shortest safe route. Time does not affect the score, and mission results do not count as course mastery.

The React frontend stores versioned exercise evidence in `localStorage` and migrates legacy mission completion IDs as history only. Learners can continue anonymously or create an account. Laravel authenticates through stateful Sanctum sessions and stores each account's progress document in MySQL; local browser storage is the offline cache and retry queue. Password reset depends on a configured mail provider. Production hosting is not configured, so the project is not ready for automatic public deployment. See [the learning plan](LEARNING-PLAN.md) for topic sequence, misconception coverage, and the reasoning behind the exercises.
