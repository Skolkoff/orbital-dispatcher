# Product overview

«Орбитальный диспетчер» is a Russian-language coordinate-plane trainer for grades 5–6. Space-themed missions help pupils read ordered pairs, find points, and reason about movement on a coordinate grid.

Five playable missions cover a point in the first quadrant, an ordered route, negative coordinates, axis reflection, and coordinate displacement. Pupils receive hints, explanations for wrong answers, retries, and progression after correct answers. The experience supports touch, keyboard interaction, and mobile through desktop layouts.

The dashboard introduces the learning goal, mission map shows locked/available/completed states, and mission screens provide interactive coordinate grids and immediate feedback. Correct completions persist locally so a learner can resume in the same browser.

The frontend phase uses mock practice services and stores only completed mission IDs in localStorage. It has no authentication, real passwords, personal data collection, or backend connection. Production deployment is configured after hosting and backend details are confirmed.
